# RMRC Reference Implementation

This folder contains a **reference implementation** of the RMRC
(Reflective Multi-Role Chat Architecture).

Purpose:
- Provide a complete, readable system overview
- Serve as a learning and validation environment
- Act as a long-lived architectural reference

Non-goals:
- Production readiness
- Performance optimization
- Deployment configuration

All code in this folder is:
- Explicit
- Conservative
- Governed by the documents in /docs
