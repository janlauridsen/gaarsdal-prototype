# Chatbot v0 · Fasttrack

Status: Experimental  
Purpose: Establish a value-producing baseline before governance

## What this is
- A flat, reflective chatbot
- Designed to feel like a “klog ven”
- Produces working reflections, not answers

## What this is NOT
- Not a diagnostic tool
- Not a recommender system
- Not governed by RMRC runtime logic

## Architecture
- Single generative prompt
- Minimal post-linting
- No roles, no lab, no governance layer

## Why this exists
RMRC is retained as a reference architecture.
This chatbot explores where real problems arise
before regulation is reintroduced.

## Next steps (later)
- Add logging if patterns emerge
- Add constraints only when needed
- Reuse RMRC elements selectively
